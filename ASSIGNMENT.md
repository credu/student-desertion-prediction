La deserción estudiantil representa uno de los principales desafíos que enfrentan las instituciones de educación superior. Identificar de manera temprana a los estudiantes con mayor riesgo de abandono permite implementar estrategias de intervención oportunas que pueden marcar la diferencia entre la permanencia y el retiro del estudiante.

En este proyecto, aplicarán técnicas de minería de datos para desarrollar un modelo predictivo que permita identificar estudiantes en riesgo de deserción, utilizando datos históricos del record académico estudiantil.

# Descripción del Problema

Se les proporciona un conjunto de datos anonimizado que contiene el historial académico de estudiantes a lo largo de varios períodos académicos. El dataset incluye información sobre materias cursadas, calificaciones, asistencia, número de veces que se ha tomado una materia, entre otros datos relevantes.

Su tarea consiste en: Analizar los datos proporcionados, identificar las variables relevantes para predecir deserción, construir un modelo de clasificación que prediga qué estudiantes tienen mayor probabilidad de retirarse, y presentar los resultados a través de una interfaz gráfica interactiva.

## Objetivo General

Desarrollar un sistema de predicción de deserción estudiantil aplicando técnicas de minería de datos, que permita identificar estudiantes en riesgo y visualizar los resultados mediante una interfaz gráfica interactiva.

## Objetivos Específicos

Realizar un análisis exploratorio del conjunto de datos para comprender su estructura y características.
Identificar y seleccionar las variables más relevantes para la predicción de deserción estudiantil.
Definir la variable objetivo (deserción) a partir de los datos históricos disponibles.
Aplicar técnicas de preprocesamiento y transformación de datos según sea necesario.
Construir y evaluar el modelo de clasificación.
Desarrollar una interfaz gráfica utilizando Streamlit para la visualización e interacción con el modelo.
Documentar el proceso metodológico siguiendo CRISP-DM.
Metodología
El proyecto debe desarrollarse siguiendo la metodología CRISP-DM (Cross-Industry Standard Process for Data Mining), documentando cada una de sus fases: comprensión del negocio, comprensión de los datos, preparación de los datos, modelado, evaluación y despliegue.
