# Sistema de Predicción de riesgo de deserción

En este proyecto, se aplicarán técnicas de minería de datos para desarrollar un modelo predictivo que permita identificar estudiantes en riesgo de deserción, utilizando datos históricos del record académico estudiantil.

## Ejecución
Entrenar el modelo.
```bash
py src/scripts/train_model.py
```

Ejecutar el servidor
```bash
streamlit run src/app.py
```
